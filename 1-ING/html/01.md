# La mia prima pagina HTML

HTML è il linguaggio utilizzato per creare e organizzare il contenuto di una pagina web.

https://www.w3schools.com/tryit/tryit.asp?filename=tryhtml_default

## Esempio

```html
<html>

<head>
    <title>Antonio</title>

    <style>
        body {
            background: red;
        }
    </style>
</head>

<body>

</body>

</html>
```

## Come è organizzata la pagina?

Una semplice pagina HTML è racchiusa tra:

```html
<html>
...
</html>
```

All'interno troviamo due parti principali:

**`<head>`**  
Contiene informazioni sulla pagina.  
Nel nostro esempio contiene:

```html
<title>Antonio</title>
```

`title` indica il **titolo della pagina**, che viene visualizzato nella scheda del browser.

Nella sezione `style` possiamo modificare l'aspetto della pagina:

```html
<style>
    body {
        background-color: red;
    }
</style>
```

`background-color` indica il **colore dello sfondo**.

Possiamo usare, per esempio:

```text
red
green
blue
yellow
white
```

**`<body>`**  
Contiene ciò che viene visualizzato **dentro la pagina web**.

Per il momento lo lasciamo vuoto:

```html
<body>

</body>
```

## Da ricordare

Molti elementi HTML hanno un **tag di apertura** e un **tag di chiusura**:

```html
<head> ... </head>
<title> ... </title>
<body> ... </body>
<html> ... </html>
```

Il tag di chiusura contiene `/`.

Esempio:

```html
<title>Antonio</title>
```

`<title>` apre l'elemento e `</title>` lo chiude.
