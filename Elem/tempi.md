# Tempi del modo indicativo

## Tempi semplici
1. Presente  
   → io mangio

2. Imperfetto  
   → io mangiavo

3. Passato remoto  
   → io mangiai

4. Futuro semplice  
   → io mangerò


## Tempi composti
5. Passato prossimo  
   → io ho mangiato

6. Trapassato prossimo  
   → io avevo mangiato

7. Trapassato remoto  
   → io ebbi mangiato

8. Futuro anteriore  
   → io avrò mangiato

# Tempi del modo congiuntivo

## Tempi semplici
1. Presente  
   → che io mangi

2. Imperfetto  
   → che io mangiassi


## Tempi composti
3. Passato  
   → che io abbia mangiato

4. Trapassato  
   → che io avessi mangiato


# Tempi del modo imperativo

## Tempo semplice
1. Presente  
   → mangia!  
   → mangiate!


## Tempo composto
2. Imperativo passato  
   → abbi mangiato  
   → siate arrivati
