# Tempi del modo indicativo

## Tempi semplici
1. Presente  
   → io mangio

2. Imperfetto  
   → io mangiavo

3. Passato remoto  
   → io mangiai

4. Futuro semplice  
   → io mangerò


## Tempi composti
5. Passato prossimo  
   → io ho mangiato

6. Trapassato prossimo  
   → io avevo mangiato

7. Trapassato remoto  
   → io ebbi mangiato

8. Futuro anteriore  
   → io avrò mangiato
