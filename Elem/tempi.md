# Verbi ausiliari

## Essere
- io sono
- io ero
- io fui
- io sarò

## Avere
- io ho
- io avevo
- io ebbi
- io avrò


# Prima coniugazione (-ARE)

## Esempio: amare

### Modo indicativo

#### Tempi semplici
1. Presente  
   → io amo

2. Imperfetto  
   → io amavo

3. Passato remoto  
   → io amai

4. Futuro semplice  
   → io amerò

#### Tempi composti
5. Passato prossimo  
   → io ho amato

6. Trapassato prossimo  
   → io avevo amato

7. Trapassato remoto  
   → io ebbi amato

8. Futuro anteriore  
   → io avrò amato


### Modo congiuntivo

#### Tempi semplici
1. Presente  
   → che io ami

2. Imperfetto  
   → che io amassi

#### Tempi composti
3. Passato  
   → che io abbia amato

4. Trapassato  
   → che io avessi amato


### Modo imperativo

#### Tempo semplice
1. Presente  
   → ama!  
   → amate!

#### Tempo composto
2. Imperativo passato  
   → abbi amato
